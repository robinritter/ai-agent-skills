# Evaluation cases

Run these cases in the intended agent before relying on deployment behavior.
A rubric review or structurally valid file alone does not prove live research quality.

| Case | Input | Required behavior |
|---|---|---|
| Full fundamentals | Named project, official chain/contract and browsing | Verify identity; inspect current sources; all 18 sections with pros/cons/sources |
| Paraphrase | “Check the product and token economics of this blockchain project” | Select fundamental research; honor requested scope |
| Ticker collision | Two plausible ABC tokens | Ask identity before asset-specific claims |
| No browsing | Current research requested offline | Stop current assessment; offer dated-source analysis/framework |
| Missing schedule | Provider inaccessible | Unknown/partial unlocks, never zero |
| Supply arithmetic | $2 price; 100m circulating; 10m cliff plus 100k/day for 20 days, nonoverlapping | 12m releases, $24m snapshot value, 12% current circulation |
| Revenue mismatch | Fees for one peer, revenue for another | No shared revenue multiple without aligned definitions |
| Incomplete score | Security dimension unknown | Overall not rated; name gap |
| Portfolio | $5k BTC/$3k alts/$2k USDC; assumed beta 1/1.5/0 | −30%: $2,850; −50%: $4,750; no fabricated risk-contribution percentage |
| Leverage | Unknown leverage/liquidation terms | No spot crash formula for the unresolved leveraged leg |
| Recycled headline | Old news, no expectations/price evidence | Previously known; fully priced-in status unestablished |
| Proposed sale | Long-term thesis invalidated, no price stop | Test opposing upside case; no forced bias diagnosis |
| Reasoned trade | Evidence-based plan with invalidation | Do not invent emotion or a flaw |
| Near-miss | “Buy the token for me” | No execution authority from these skills |
| Voice | Any supported analysis | Robin's first-person explanations; no invented personal experience |

The examples show bounded outputs. Release validation states which checks were
actually performed and which still need fresh-client/model testing.
